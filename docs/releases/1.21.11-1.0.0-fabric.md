# The Aether Minecraft 1.21.11（Fabric 1.0.0 正式版）

这是 The Aether 面向 Minecraft 1.21.11 Fabric 的首个正式版本，完成了核心玩法、客户端渲染、网络同步与饰品系统从 NeoForge 基线到 Fabric 的迁移和稳定化。

## 更新亮点

- 将 The Aether 完整适配到 Minecraft 1.21.11、Fabric Loader 0.18.4 与 Fabric API 0.141.3+1.21.11。
- 使用 Fabric 事件与 Mixin 桥接恢复传送门、维度数据、玩家生命周期、睡眠、弹射物、坐骑和自然生成逻辑。
- 重建 Aether 饰品的持久化、同步、自动装备和渲染流程，并恢复第三人称、第一人称、盔甲架及鞘翅行为。
- 恢复 Aether 天空、天气、雾效、昼夜时间线以及生物模型、导航和透明渲染效果。
- 修复 Book of Lore 的服务端触发、页面同步、文本回退与绘制层级。
- 迁移 JEI、Jade 与 REI 集成 API，并恢复 Aether 配方分类及物品可见性。
- 修复传送门 POI、资源包元数据、物品模型、纹理图集、Boss 对话和专用服务器网络线程等兼容问题。
- 加强饰品附件在保存与同步期间的并发安全，修复坐骑、友好 Swet、Slider、Sun Spirit 和自然生成等运行时问题。

## 兼容性说明

- 本构建仅面向 Minecraft 1.21.11 Fabric，不兼容 NeoForge 或其他 Minecraft 版本。
- JEI、Jade、REI、Twilight Forest 等集成会按对应依赖是否安装进行可选加载。
- 该版本使用内置的 Aether 饰品实现，不要求额外安装 Accessories 模组。

## 验证与发布

- GitHub Actions 使用 Java 21 执行全新的 `clean test build`。
- 发布流程检查正式版标签、更新通道、JAR 内嵌版本以及主 JAR 与 sources JAR 是否齐全。
- 工作流会上传两个发布文件，并在本说明末尾附加各自的 SHA-256 校验和。

## 运行环境

- Minecraft 1.21.11
- Fabric Loader 0.18.4
- Fabric API 0.141.3+1.21.11
- Java 21

## 维护范围

`1.21.11-fabric` 分支继续保留，用于 Minecraft 1.21.11 的维护与回归修复；更高 Minecraft 版本的功能开发在各自版本分支进行。
