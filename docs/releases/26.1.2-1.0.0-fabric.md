# The Aether Minecraft 26.1.2（Fabric 1.0.0 正式版）

这是 The Aether 面向 Minecraft 26.1.2 Fabric 的首个正式版本，汇总并稳定了从 1.21.11 Fabric 版本线迁移而来的运行时与客户端兼容工作。

## 更新亮点

- 将 The Aether 完整升级到 Minecraft 26.1.2、Fabric Loader 0.19.2 与 Fabric API 0.149.0+26.1.2。
- 修复 26.1.2 数据包注册表加载、维度时钟同步、修复配方以及 Aether 草方块骨粉行为。
- 适配新的玩家渲染器、雾渲染、云层渲染和 Skyroot Bed 物品模型。
- 调整 Book of Lore 页面为独立覆盖层，并修复换行文本渲染。
- 加强饰品状态并发访问、非 Aether 世界时间更新及专用服务器客户端类隔离。
- 修复 JEI 插件在 Minecraft 26.1.2 上的启动与配方类型兼容问题。
- 拆分 Fabric 事件、维度、实体、GUI、覆盖层和 JEI 辅助边界，降低后续版本迁移成本。

## 兼容性说明

- 该构建仅面向 Minecraft 26.1.2 Fabric，不兼容 NeoForge 或其他 Minecraft 版本。
- 本版本继承 1.21.11 Fabric 版本线中的 Aether 饰品、传送门、世界生成、网络同步及客户端渲染兼容实现。
- JEI、Jade、REI 等集成仍按各自依赖是否安装进行可选加载。

## 验证与发布

- GitHub Actions 使用 Java 25 执行全新的 `clean test build`。
- 发布流程检查 JAR 内嵌版本、正式版标签、更新通道以及主 JAR 和 sources JAR 是否齐全。
- 工作流会上传两个发布文件，并在本说明末尾附加各自的 SHA-256 校验和。

## 运行环境

- Minecraft 26.1.2
- Fabric Loader 0.19.2
- Fabric API 0.149.0+26.1.2
- Java 25

## 已知范围

这是针对 26.1.2 版本线的正式归档版本。后续功能开发与更广泛的第三方模组兼容工作转移到 Minecraft 26.2 分支；26.1.2 分支继续保留用于该游戏版本的维护与回归修复。
