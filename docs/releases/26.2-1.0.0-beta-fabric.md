# The Aether for Minecraft 26.2 (Fabric beta)

This prerelease packages the Fabric-native migration work on `codex/fabric-native-refactor`.

## Highlights

- Replaced the Forge-shaped configuration facade with Aether-native configuration storage, lifecycle handling, and server-to-client synchronization.
- Restored compatible reads for released Boss NBT and isolated legacy player data migration while preserving unknown third-party NBT.
- Hardened Fabric networking authority, tracking scope, attachment synchronization, and per-player travel state.
- Restored released built-in resource/data pack discovery without a cross-loader runtime dependency.
- Updated Minecraft 26.2 Mixins and client rendering paths for Aether time, sky/fog, HUD hearts, dungeon lock overlays, Moa layers, and resource reloads.
- Added registry/resource stability guards and migration/config/network tests.

## Validation

- GitHub Actions performs a fresh `clean build` with Java 25 before creating this release.
- Local release qualification passed 32 tests across 12 suites, with no failures, errors, or skips.
- A real Fabric 26.1.2 save copy upgraded to 26.2 and passed Aether dimension travel, containers, persisted Moa interaction, death/respawn attachment copying, Slider and Valkyrie Queen completion, dungeon unlock persistence, resource reload, disconnect cleanup, and repeated server restarts.
- The original 70-file save manifest remained unchanged.
- 585 native registry identifiers match the released 26.1.2 Fabric baseline; 2,768 packaged JSON files and core Aether model, texture, atlas, sound, and particle references passed integrity checks.

## Runtime

- Minecraft 26.2
- Fabric Loader 0.19.3
- Fabric API 0.153.0+26.2
- Java 25

## Scope

This is a beta prerelease. Live old-save validation covers the supplied Fabric save and The Aether itself. Forge/NeoForge saves and unrelated Mods were not part of this release acceptance scope. The strict project-wide migration audit remains `MIGRATING` for scenarios not represented by that fixture.
