# The Aether for Minecraft 26.2 (Fabric beta 1.0.1)

This prerelease adds complete Aether accessory-core bridges for supported vanilla items and the current Twilight Forest Fabric accessory declarations.

## Highlights

- Made accessory slot resolution deterministic and exclusive for death-protection items, Elytra, shields, Aether accessories, and the generic `accessories:*`, `curios:charm`, and `curios:head` tags.
- Added server-authoritative atomic accessory queries and mutations with immediate attachment persistence, tracking-and-self synchronization, and single unequip callbacks.
- Added vanilla death-protection, back-slot Elytra, firework, durability, enchantment, Mending, shield-blocking, animation, and rendering bridges.
- Added tag-driven right-click equip and visible/cosmetic rendering for generic charm and head accessories.
- Added an isolated optional Twilight Forest bridge for Charm of Life and Charm of Keeping consumption without a Curios, Accessories, Trinkets, Forge, NeoForge, or Twilight Forest runtime dependency.
- Added Twilight Forest Cicada moving sound handling for visible Aether accessories, including cleanup on hiding, removal, death, dimension changes, and entity untracking.

## Compatibility safety

- Aether does not link Twilight Forest classes when Twilight Forest is absent.
- The optional pseudo-Mixin applies only when `twilightforest` is loaded and precisely targets the current Minecraft 26.2 `TFItemStackUtils.consumeInventoryItem(Player, ItemLike, CompoundTag, boolean)` signature.
- Inventory and vanilla equipment consumption retain priority over Aether accessory slots.
- Consumed charms are persisted and synchronized immediately, and `CharmStack` preserves the complete pre-consumption item stack when requested by Twilight Forest.

## Validation

- The complete local Gradle test suite passed 44 tests with no failures, errors, or skips.
- `test build` and `git diff --check` completed successfully on Java 25.
- Aether-only client and dedicated-server startup passed.
- Aether plus Twilight Forest client and dedicated-server startup passed, with the optional compatibility Mixin confirmed as applied on both sides.

## Runtime

- Minecraft 26.2
- Fabric Loader 0.19.3
- Fabric API 0.153.0+26.2
- Java 25

## Scope

This remains a beta prerelease. Automated tests and startup-matrix validation cover slot resolution, transaction ordering, optional class loading, and release builds. In-world multiplayer qualification of every charm effect, shield combat edge case, Elytra render transition, cosmetic toggle, death/respawn, reconnect, and dimension-change combination remains recommended before treating the compatibility matrix as final.

The release workflow appends the exact SHA-256 checksums produced by the remote build.
