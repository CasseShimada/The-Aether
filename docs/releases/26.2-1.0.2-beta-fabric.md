# The Aether Minecraft 26.2（Fabric 1.0.2 测试版）

本次预发布新增了对 Diggus Maximus 1.5.9-beta.1+26.2、Carry On 2.9.1 和 WTHIT 20.0.0 的可选公共 API 兼容支持。

## 更新亮点

- 新增 Diggus Maximus API 1 数据标签，覆盖三类 Aether 矿石及常规 Aether 采掘工具。不同矿石族保持独立分组；地下城状态机方块、传送门、方块实体、动态方块、饰品、武器、护甲以及特殊/AoE 工具均采用安全拒绝策略。
- 新增 Carry On API 1 搬运标签。祭坛、冷冻机和孵化器等普通机器与容器可以携带完整的原版方块实体数据进行搬运；地下城结构、世界绑定或动态方块、敌对/瞬态实体以及不安全的堆叠目标会被拒绝。
- 新增 WTHIT 20 通用端/客户端插件，并且仅使用公开的 `mcp.mobius.waila.api` 接口。普通玩家看到的陷阱方块和门廊会替换为安全外观，宝箱怪会显示为普通箱子；创造模式与旁观模式玩家仍可查看真实对象，以便进行管理和排障。
- 将原有 Jade 集成迁移到 Jade 26.2.9 的公开 Fabric API 和自定义入口点，并让 Jade 与 WTHIT 共用一套与查看器无关的外观判定策略，避免两套隐私行为发生偏差。宝箱怪被隐藏时，两种查看器都会保留不泄露敏感信息的“库存内容尚未生成”提示。

## 兼容性与安全性

- 三项集成均为可选功能。The Aether 在运行时不依赖 Diggus Maximus 或 Carry On；只有安装 WTHIT 后，WTHIT 才会通过其插件描述符发现对应集成类。
- Diggus Maximus 与 Carry On 集成均由数据驱动，使用 Minecraft 26.2 的单数注册表标签路径，并通过 `replace: false` 进行增量合并。
- Carry On 对不安全方块使用硬性约定标签 `c:relocation_not_supported`。审计确认原版完整方块实体序列化可以保留 Aether 机器状态，因此无需注册 `CarryDataExtension`。
- WTHIT 的服务端数据提供器根据权威服务端玩家状态决定是否隐藏宝箱怪，并阻止向被隐藏视图发送物品数据；客户端适配层无权决定是否发送隐藏库存数据。
- 发布产物不会捆绑 Diggus Maximus、Carry On、WTHIT 或 Jade 的实现类和 JAR。

## 验证情况

- Java 25 单元测试和 GameTest 覆盖了标签路径与内容、依赖版本范围、可选类加载边界、外观映射、受保护方块拒绝、矿石族隔离、每次实际连锁挖掘仅结算一次耐久与掉落、Carry On 方块实体保存/重载及取消恢复，以及危险实体与堆叠目标拒绝。
- 直接 API 集成测试使用本地工作树构建出的精确版本 Diggus Maximus 1.5.9-beta.1+26.2 和 Carry On 2.9.1，同时不会向正式发布构建加入本地路径或本地产物依赖。
- 真实客户端 GameTest 分别在未安装查看器、仅安装 Jade 26.2.9、仅安装 WTHIT 20.0.0，以及同时安装两种查看器时进入单人世界。Jade/WTHIT 测试会捕获普通玩家和创造模式玩家的宝箱怪覆盖层，并确认两种查看器同时加载时不会产生矛盾或重复的身份信息。专用服务器测试覆盖 The Aether 单独安装、分别搭配每个目标模组、四个模组同时安装，以及同一世界的第二次加载。
- GitHub 发布工作流在 Java 25 下执行干净的 `test build`，检查打包后的描述符、标签以及禁止出现的第三方/测试包，上传主 JAR 和 sources JAR，并在下方附加精确的 SHA-256 校验和。

## 运行环境

- Minecraft 26.2
- Fabric Loader 0.19.3
- Fabric API 0.153.0+26.2
- Java 25

## 已知限制

- 对于安全性取决于地下城、传送门、多方块结构或动态世界状态的 Aether 对象，静态标签会主动拒绝操作，而不会尝试通过宽松回调绕过这些不变量。
- 客户端自动化证据直接覆盖宝箱怪的隐私边界；陷阱方块和门廊映射通过共享的、基于注册表的 GameTest 策略验证，并未对每一种方块变体逐一进行像素级比较。
- 本版本仍为测试版。在大型整合包中作为生产稳定版本使用前，仍建议结合第三方配置覆盖与数据包进行多人环境验证。

发布工作流会附加远端构建产物的精确 SHA-256 校验和。
