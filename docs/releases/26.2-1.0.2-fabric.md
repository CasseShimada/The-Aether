# The Aether Minecraft 26.2（Fabric 1.0.2 正式版）

这是 The Aether 面向 Minecraft 26.2 Fabric 的首个正式版本，汇总 1.0.0 至 1.0.2 测试版的 Fabric 原生迁移、饰品兼容和第三方公共 API 集成成果。

## Fabric 原生迁移

- 使用 Aether 原生配置存储、生命周期和服务端到客户端同步替代 Forge 风格的配置外观层。
- 加强 Fabric 网络权限、实体跟踪范围、附件同步和逐玩家维度旅行状态管理。
- 保留已发布 Boss NBT 与旧玩家数据的兼容读取，并在迁移时保留未知第三方 NBT。
- 恢复内置资源包与数据包发现，稳定注册表标识符、资源引用以及 Minecraft 26.2 的键控物品、方块和实体注册。
- 更新天空、雾、HUD 心形、地下城锁定覆盖层、Moa 渲染层和资源重载等客户端路径。

## 饰品兼容

- 为保命物品、鞘翅、盾牌、Aether 饰品以及通用 charm/head 标签提供确定且互斥的槽位解析。
- 支持服务端权威的饰品查询、装备、卸下、持久化和跟踪同步。
- 衔接原版保命、鞘翅飞行与烟花、耐久、附魔、经验修补、盾牌格挡、动画和可见/装饰渲染行为。
- 提供隔离的可选 Twilight Forest 兼容，在未安装 Twilight Forest 时不会链接其实现类。

## 第三方公共 API

- 通过数据标签支持 Diggus Maximus 1.5.9-beta.1+26.2，并对地下城、传送门、动态方块及特殊工具采用安全拒绝策略。
- 通过公开搬运标签支持 Carry On 2.9.1；普通机器和容器可以保留完整方块实体数据，危险对象和堆叠目标会被拒绝。
- 使用 WTHIT 20.0.0 公开 API 提供服务端权威的陷阱、门廊和宝箱怪外观保护。
- 将 Jade 集成迁移到 Jade 26.2.9 的公开 Fabric API，并让 Jade 与 WTHIT 共用同一套查看器无关外观策略。
- 发布 JAR 不捆绑 Diggus Maximus、Carry On、WTHIT、Jade 或 Twilight Forest 的实现类和 JAR。

## 验证与发布

- GitHub Actions 使用 Java 25 执行全新的 `clean test build`，并检查正式版版本号、更新通道和发布资产。
- 单元测试与 GameTest 覆盖配置、迁移、网络、注册表、饰品事务、可选类加载、API 标签、外观映射和危险操作拒绝。
- 客户端及专用服务器组合测试覆盖 The Aether 单独运行，以及与目标兼容模组分别或同时安装的场景。
- 工作流上传主 JAR 和 sources JAR，并在本说明末尾附加各自的 SHA-256 校验和。

## 运行环境

- Minecraft 26.2
- Fabric Loader 0.19.3
- Fabric API 0.153.0+26.2
- Java 25

## 已知范围

- 静态兼容标签继续拒绝安全性依赖地下城、传送门、多方块结构或动态世界状态的对象。
- 在大型整合包中使用前，仍建议结合第三方配置覆盖、数据包与多人环境进行回归验证。
